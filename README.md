# richgibbs.dev — Portfolio

Personal portfolio and developer showcase for **Rich Gibbs**, live at [richgibbs.dev](https://richgibbs.dev).

## Overview

This repository contains the static HTML/CSS portfolio site for richgibbs.dev — a personal site showcasing:

- Full-stack development projects
- Technical writing and blog posts
- Skills in Node.js, Next.js, TypeScript, AWS, Cloudflare, and more
- SaaS micro-products built and shipped

## Tech Stack

- Pure HTML5 + CSS3 (no framework dependencies)
- Hosted on AWS EC2 behind Cloudflare
- Served via Apache

## Projects Featured

- **ListingLift** — AI-powered Etsy listing optimizer
- **Checkpoint** — Automated QA testing platform
- And more indie software experiments

## Development

This is a static site. To update it, edit `index.html` directly and redeploy.
